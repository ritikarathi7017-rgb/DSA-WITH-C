## ▶️ How to Run a C Program

1. Open the repository in GitHub Codespaces or a local development environment.
2. Open the terminal.
3. Compile a C file using GCC:

```bash
gcc filename.c -o program
```

4. Run the compiled program:

```bash
./program
```

Replace `filename.c` with the name of the C file you want to execute.
